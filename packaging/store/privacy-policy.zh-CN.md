# 声麦 Studio Pro 隐私政策

**生效日期：2026-10-22**
**适用版本：声麦 Studio Pro 1.0 及以后**
**开发与发布：IMXia-Chan**

## 一、总则

声麦 Studio Pro（以下简称“本软件”）是一款在用户自己的电脑上运行的录音与混音软件。本软件**不设立用户账号，不收集使用统计，不内置任何遥测或分析服务**。本政策说明：本软件会接触哪些数据、这些数据存放在哪里、以及在什么情况下会离开本机。

## 二、始终保存在本机的内容

以下内容全部存放在本机，不上传、不同步、不备份到任何服务器：

- 录音、导入的音频、生成的伴奏与导出成品；
- 工程文件、媒体库索引、渲染缓存；
- 界面语言、快捷键与偏好设置；
- 用户自行填写的 API Key（存于本机 `%USERPROFILE%\.singmic\` 目录，仅本机进程可读）。

安装版的数据目录为 `%LOCALAPPDATA%\SingMic\data`；卸载本软件不会自动删除该目录，用户可自行删除。

## 三、麦克风

本软件在用户点击录音、或启用音高检测与节拍分析时访问麦克风。音频数据只写入本机文件，不发送到网络。麦克风的使用完全由用户的操作触发，软件不会在后台持续录音。

## 四、联网功能与数据流向

本软件默认不需要联网。以下功能由用户**主动触发**，并且只使用用户自己配置的服务与密钥：

| 功能 | 发送的内容 | 接收方 |
|---|---|---|
| AI 伴奏生成 | 用户输入的风格描述、歌词、时长与调式 | 用户在设置中选择并配置 API Key 的服务平台 |
| 调音助手（自然语言调参） | 用户输入的一句话，以及工程中**轨道与音频块的参数**（增益、声像、插件参数、音高偏移等） | 用户自行配置的 DeepSeek 接口 |
| 个人音色补音 | **用户选中的那一段音频**（不超过 15 秒） | 用户自行搭建的推理服务器（未配置时在本机运行，不发送） |

明确不发送的内容：完整歌曲、其他音轨的音频、文件路径、文件名、工程名、以及任何与本机相关的标识信息。用户未配置相应服务时，上述功能不可用，软件不会自行连接任何服务器。

AI 伴奏生成与调音助手会把内容交给第三方服务平台处理，该平台对数据的处理适用其自身的隐私政策。

## 五、模型文件

语音识别与 AI 降噪使用本地模型，模型文件在用户确认后从公开地址下载到本机，下载过程不携带任何用户数据。

## 六、儿童

本软件不面向儿童单独收集任何信息，也不存在账号体系。

## 七、数据删除

删除本机的工程文件、媒体文件或整个数据目录，即可删除对应数据。本软件不在任何服务器上保留用户数据的副本。

## 八、政策变更

本政策如有变更，将随软件版本更新发布，并在本页面标注新的生效日期。
